สร้างกุญแจ VAPID สำหรับแจ้งเตือนมือถือ

กดปุ่มด้านล่างเพื่อสร้างกุญแจคู่ใหม่ ในเครื่องของคุณเอง (ไม่มีข้อมูลถูกส่งออกไปที่ไหน) ทำครั้งเดียวตอนติดตั้ง

กุญแจส่วนตัว (Private) เป็นความลับ ห้ามส่งให้ใคร ห้ามใส่ใน GitHub หรือใน index.html
ใส่ได้เฉพาะในช่อง Secret ของ Cloudflare Worker เท่านั้น

ถ้ากดสร้างใหม่อีกครั้ง กุญแจเดิมจะใช้ไม่ได้ และสมาชิกต้องกด "เปิดแจ้งเตือน" ใหม่ทุกคน
